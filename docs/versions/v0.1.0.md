# Light Dock 0.1.0 — 单层稳定基线

[返回首页](../../README.md) · [源码](https://github.com/ChaiTaishuai/LightDock/tree/v0.1.0) · [下载](https://github.com/ChaiTaishuai/LightDock/releases/tag/v0.1.0)

## 这个版本提供什么

单排图标栏、悬停放大、横竖排列、自由拖动，以及桌面图标收纳和退出恢复。

Light Dock 将常用文件、文件夹和快捷方式集中到桌面图标栏，减少在桌面上寻找入口的时间。收纳不移动原文件，退出程序时恢复被收纳的桌面图标。

## 操作

将文件、文件夹或快捷方式拖入图标栏，点击打开；悬停放大方便定位。通过设置调整图标尺寸、透明度及横竖排列，拖动背板移动图标栏。本版没有二级分组。双击桌面空白处可隐藏或恢复 Dock、桌面图标与任务栏。

## 安装、升级和退出

完整解压 Windows x64 ZIP 到当前用户可写目录，运行 `bin/AsterDock.exe`，保留旁边的 `.config` 文件。需要 .NET Framework 4.8；目标平台为 Windows 11 或 Windows 10 1607+ x64，系统视觉效果可能不同。不要在 ZIP 内运行。配置位于与 `bin` 同级的 `data/settings.xml`。切换版本前先退出正在运行的 Dock，并备份自己的配置。

## 验证边界

本版本源码已在本地和 GitHub Actions 中成功编译。云端构建不等于交互验收；多电脑、实体多屏混合 DPI 和实际注销登录场景尚未完成全面验证。程序未数字签名。历史版本缺少后续修复，日常使用建议选择 0.3.0。

早期 EXE 的内部版本资源为 `0.0.0.0`，以下载包名称和对应标签辨认版本。

## English guide

**Single-level stable baseline.** A single-row dock, hover magnification, horizontal/vertical layout, free positioning and restoration of managed desktop icons.

Light Dock collects frequently used files, folders and shortcuts into a desktop launcher. It keeps original files in place and restores managed desktop icons on exit.

Extract the entire archive to a user-writable folder and run `bin/AsterDock.exe`. Keep its `.config` file. Settings live in `data/settings.xml` beside `bin`. Exit any running version before switching and back up your settings. These unsigned builds require Windows x64 and .NET Framework 4.8. Local and CI compilation passed; cross-PC, physical mixed-DPI displays and real sign-in scenarios are not fully validated. Prefer 0.3.0 for daily use.
