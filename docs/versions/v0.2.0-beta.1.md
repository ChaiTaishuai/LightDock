# Light Dock 0.2.0-beta.1 — 二级分组

[返回首页](../../README.md) · [源码](https://github.com/ChaiTaishuai/LightDock/tree/v0.2.0-beta.1) · [下载](https://github.com/ChaiTaishuai/LightDock/releases/tag/v0.2.0-beta.1)

## 这个版本提供什么

一级最多 12 个图标；二级分组、展开收起、组内滚动、跨组拖动及排序。

Light Dock 将常用文件、文件夹和快捷方式集中到桌面图标栏，减少在桌面上寻找入口的时间。收纳不移动原文件，退出程序时恢复被收纳的桌面图标。

## 分组与操作

- **常用入口**：一级区域最多放置 12 个图标，保留最常访问的项目。
- **展开/收起**：点击右侧三角显示或收起二级区域；收起后仍保留一级入口。
- **创建分组**：右键背板、分组或图标，选择新建分组，输入名称。右键分组标题可重命名或删除；删除组后项目回到“未分组”。
- **拖放整理**：将文件、文件夹或快捷方式拖入目标区域；组间拖动可改变归属，放到其他图标上可插入排序。一级已满时不会继续接受二级项目。
- **浏览更多项目**：二级最大可见行数可设置为 2–8 行；内容较多时在组内滚动。列数跟随一级图标数变化。
- **回到桌面**：将收纳项目拖回桌面空白处或移除；退出程序也会恢复桌面。

## 安装、升级和退出

完整解压 Windows x64 ZIP 到当前用户可写目录，运行 `bin/LightDock.exe`，保留旁边的 `.config` 文件。需要 .NET Framework 4.8；目标平台为 Windows 11 或 Windows 10 1607+ x64，系统视觉效果可能不同。不要在 ZIP 内运行。配置位于与 `bin` 同级的 `data/settings.xml`。切换版本前先退出正在运行的 Dock，并备份自己的配置。

## 验证边界

本版本源码已在本地和 GitHub Actions 中成功编译。云端构建不等于交互验收；多电脑、实体多屏混合 DPI 和实际注销登录场景尚未完成全面验证。程序未数字签名。历史版本缺少后续修复，日常使用建议选择 0.3.0。

早期 EXE 的内部版本资源为 `0.0.0.0`，以下载包名称和对应标签辨认版本。

## English guide

**Expandable groups.** Up to 12 primary icons, expandable groups, internal scrolling, cross-group dragging and ordering.

Light Dock collects frequently used files, folders and shortcuts into a desktop launcher. It keeps original files in place and restores managed desktop icons on exit.

Keep up to 12 favorites in the primary row. Click the triangle to expand or collapse the secondary groups. Right-click the background or group to create a group; right-click its heading to rename or remove it. Drag items between groups or onto another icon to reorder them. Scroll inside a group to reach additional items. Settings offer 2–8 visible rows; removing a group returns its items to Ungrouped.

Extract the entire archive to a user-writable folder and run `bin/LightDock.exe`. Keep its `.config` file. Settings live in `data/settings.xml` beside `bin`. Exit any running version before switching and back up your settings. These unsigned builds require Windows x64 and .NET Framework 4.8. Local and CI compilation passed; cross-PC, physical mixed-DPI displays and real sign-in scenarios are not fully validated. Prefer 0.3.0 for daily use.
