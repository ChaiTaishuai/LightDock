# Light Dock 0.3.0 — unsigned Windows x64 release

Extract the entire ZIP to a permanent folder writable by your user account, then run bin/LightDock.exe. Keep the EXE and its .config file together. Settings are stored in the data folder beside bin, created on first use. Do not run directly inside the ZIP.

Requirements: Windows 11 x64, or Windows 10 version 1607 or newer x64 with .NET Framework 4.8 installed. Windows 11 glass/corner effects may differ on Windows 10. Other PCs have not yet been physically tested.

Open Settings from the tray or Dock menu. Language offers System default, Simplified Chinese and English. Chinese Windows display languages use Simplified Chinese; other languages use English. Custom item and group names are preserved.

To start at sign-in, enable the startup checkbox in Settings. Re-enable it after moving the app. If disabled in Windows Startup Apps, enable it there too. Windows may delay launch. Real sign-out/sign-in testing is still pending.

To exit, use Exit and restore desktop in the tray menu. Before uninstalling, turn off startup, exit, and delete the extracted folder. Back up data/settings.xml if you wish to keep your layout.

This build is NOT digitally signed. Its SHA-256 checksum verifies file equality, not publisher identity or absence of malware. No security exclusions or firewall rules are installed. Security prompts may depend on your computer policy.
